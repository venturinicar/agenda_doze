#  🌍 Quinto Projeto - Desenvolvimento WEB

Este projeto tem como objetivo entender sobre HTML e poder criar nossas páginas WEB.

## 🎯 Objetivo

Noções sobre código fonte de paginas, criação de páginas WEB usando bloco de notas, utilização da linguagem de marcação HTML, programação e elaboração de código utilizando VS Code, noções sobre o termo IntelliSense, Praticar criação de página utilizando VS Code.

## 👨🏼‍💻Analise e Resultados
